Install (about 5 minutes)

1

Unzip. Windows: right-click News-Clarity.zip → Extract All… (Chrome can't load from inside a ZIP). Mac: double-click. Move the resulting News-Clarity folder to Documents and leave it there.

2

Go to chrome://extensions, switch on Developer mode (top right), click Load unpacked.

3

Select the news-clarity folder (the one containing manifest.json). The card appears:

4

The settings page opens by itself. Choose ChatGPT or Grok, the language, the text size → Save.

5

Pin it: puzzle-piece icon 🧩 → pin next to News Clarity. Make sure the person is logged in to chatgpt.com or grok.com in this Chrome.

Quick test

Open any news article → blue icon → Sprawdź ten artykuł → a ChatGPT tab opens → click the message box → Ctrl+V (Mac Cmd+V) → Enter. The answer should start with a one-line verdict and follow the News Clarity sections, with sources.

Good to know

  • "Developer mode extensions" warning at Chrome start-up is expected for extensions installed this way. Tell Dad to close it. To get rid of it for good, publish the extension as an unlisted Chrome Web Store item (one-off $5 developer fee) and install it from there.
  • Permissions: Chrome says it can "read and change data on all websites". It only reads the page when the button or right-click menu is used, to get the article text. Nothing runs in the background and nothing is sent anywhere except the chat site you open.
  • Cost: nothing beyond the existing ChatGPT/Grok subscription. (Optional Claude API mode in settings needs a separate API key and is billed per use.)

Updating to a new version

  1. Unzip the new package.
  2. Replace the contents of the old news-clarity folder with the new one (same location).
  3. On chrome://extensions, press ↻ on the News Clarity card. Settings are kept.

Troubleshooting

SymptomFix
"Manifest file is missing or unreadable"Wrong folder level: pick news-clarity, the folder with manifest.json in it.
Extension disappeared or shows an error after a restartThe folder was moved, deleted, or still inside the ZIP. Unzip it to a permanent place and load again.
Nothing pastes into ChatGPTBack in the panel, click Skopiuj jeszcze raz (Copy again).
"Can't read this page"Chrome pages, the Web Store and some PDFs block extensions. Select text → right-click, or paste it into the panel.
Answer has no sources / didn't searchAsk in the chat: "Check this against current sources." On ChatGPT, the web-search option can also be switched on in the message box.
