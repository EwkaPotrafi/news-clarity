# Setting this up for Dad (no coding needed)

Dad doesn't need this repository. He needs a Claude Project that carries the
same instructions, so every question he asks gets the same method.

## One-time setup (on his account, or yours shared with him)
1. Go to claude.ai → **Projects** → **Create project**.
2. Name it something friendly, e.g. **"Wiadomości bez emocji"** (News without the noise).
3. Open **Project instructions** and paste everything in `CLAUDE.md` from the
   top down to (not including) the section "Working in this repository".
4. Make sure web search is switched on, so answers use current reporting.

## How he uses it
He opens the project and either:
- pastes a link or a forwarded message and asks **"Czy to prawda?"** (Is this true?), or
- asks a plain question: **"O co chodzi z …?"** (What's going on with …?)

He can write in Polish or English; the answer comes back in the same language.

## Tips to pass on
- The **"Pewność"** (confidence) line matters most: low confidence means
  "wait before sharing".
- If an answer ever feels like it's taking sides, send it to Ewa. That's a
  signal to adjust the instructions.

## Keeping it in sync
When `CLAUDE.md` changes in the repository, paste the updated text into the
project instructions too.
